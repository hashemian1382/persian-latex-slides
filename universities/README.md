# پیش‌تنظیم دانشگاه‌ها

هر فایل این پوشه سه چیز را یک‌جا تنظیم می‌کند: **رنگ‌ها**، **لوگو** و **نام
دانشگاه و دانشکده**. در `main.tex` یکی را بار کنید:

```latex
\input{universities/sharif.tex}
```

## ترتیب مهم است

```
\usetheme{PersianThesis}        ← قالب
\input{universities/xxx.tex}    ← پیش‌تنظیم دانشگاه
\input{config/info.tex}         ← مشخصات شما، بر پیش‌تنظیم مقدم است
\input{config/fonts.tex}        ← همیشه آخر
```

هر چیزی که در `config/info.tex` بنویسید، مقدارِ پیش‌تنظیم را بازنویسی می‌کند. پس
می‌توانید پیش‌تنظیم را دست نزنید و فقط نام دانشکده را در `info.tex` عوض کنید.

## فایل‌های موجود

| فایل | دانشگاه |
|---|---|
| `default.tex` | بی‌نام، با طرح‌رنگ `indigo` — نقطهٔ شروع بی‌طرف |
| `sharif.tex` | صنعتی شریف |
| `tehran.tex` | تهران |
| `amirkabir.tex` | صنعتی امیرکبیر |
| `ferdowsi.tex` | فردوسی مشهد |

## ساختن پیش‌تنظیم تازه

یکی از فایل‌ها را کپی کنید و سه رنگ را عوض کنید:

```latex
\PTsetup{
  primary   = 1C3F72,   % رنگ اصلی: عنوان‌ها، جداکنندهٔ فصل، جعبهٔ تعریف
  secondary = 33639E,   % رنگ دوم: جعبهٔ مثال، پیوندها
  accent    = C08A2E,   % رنگ تأکید: \hl، نوار پیشرفت، جعبهٔ نکته
  logo      = figures/logos/my-university.pdf,
}
\university{نام کامل دانشگاه}
\shortuniversity{نام کوتاه، برای پانویس}
\faculty{دانشکدهٔ مهندسی کامپیوتر}
\department{}
```

سه راهنمای کوچک برای انتخاب رنگ:

* `primary` را **تیره** بگیرید (روشنایی زیر ۴۰٪) تا متن سفید رویش خوانا باشد.
* `secondary` روشن‌ترِ همان فام باشد، نه یک فام تازه.
* `accent` باید **مکمل** یا دست‌کم دور از `primary` باشد؛ همین است که به چشم
  می‌آید و باید کم به کار برود.

اگر ترجیح می‌دهید رنگ نسازید، یکی از هفت طرح‌رنگ آماده را بردارید:

```latex
\PTsetup{palette = navy}   % indigo navy teal maroon forest plum graphite
```

## سلب مسئولیت

رنگ‌های این فایل‌ها **تقریبی و چشمی** انتخاب شده‌اند تا نزدیک به حس نشان هر
دانشگاه باشند؛ هیچ‌کدام سند رسمی هویت بصری نیستند. اگر دانشگاه‌تان راهنمای رنگ
رسمی دارد، همان کدها را بگذارید.
